# Iris Flower Classification

## Project Overview
This project classifies Iris flowers into three species: Setosa, Versicolor, and Virginica using machine learning.

## Dataset
- 150 samples
- 4 numerical features
- 3 flower species
- No missing values

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Methodology
1. Loaded and explored the Iris dataset.
2. Visualized feature relationships using pairplots.
3. Split the dataset into 80% training and 20% testing data.
4. Applied StandardScaler for Logistic Regression.
5. Trained Logistic Regression and Decision Tree classifiers.
6. Evaluated models using accuracy, precision, recall, F1-score, and confusion matrices.
7. Visualized decision boundaries using petal length and petal width.

## Results

| Model | Accuracy |
|---|---:|
| Logistic Regression | 93.33% |
| Decision Tree | 93.33% |

Both models achieved the same accuracy on the test set.

## How to Run
1. Install the required libraries.
2. Keep `iris.csv` and `iris_classification.ipynb` in the same folder.
3. Open the notebook in Jupyter or VS Code.
4. Run the cells from top to bottom.
